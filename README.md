# Tartarus Overlay

Razer Synapse 4 に出ている Razer Tartarus Pro の絵に、今のプロファイルのキー割り当てを重ねて出す Windows 用のツールです。

- ダウンロード：右の「Releases」から、いちばん新しい版の `TartarusOverlay.exe` を取ってください
- 使い方は、最初に渡した zip の中の「説明書.txt」を見てください
- v7.12 から、オーバーレイが起動したとき（1日1回）に、ここの新しい版があるか確かめます。あれば右下に知らせが出て、「更新する」を押すと入れ替わります（設定はそのまま）
- ⚙ のメニューの「新しい版を確かめる」でも確かめられます

このページには exe（Releases）だけを置いています。
